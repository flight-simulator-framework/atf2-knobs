Online COD Correction
1998.10.30 K.KUBO
1. Take Orbit data using BPM window.
(EXEC. Average Store Orbit into Memory)
2. Store the data in a file. (SAVE TO FILE) Let's call this file_1.
3. Open SAD - COD CORRECTION - OPEN MENU BPM DATA to SAD
4. Chose file_1 as 'FILE A'.
5. Select 'FILE A' and 'Copy' and click 'To SAD Buffer'
(You can see the data in the SAD Buffer in BPM window.)
(You can select BPMs to be used from SAD - COD CORRECTION - 
OPEN MENU BPM DATA to SAD - OPEN MENU BPM SELECTION before the click)
6. Select H or V (to select both is not recomended, may cause error)
Put number of strees to be used.
7. Click 'CALC'.
The calculation may a few min.
The measured COD (plot) and fitted COD will be seen on
'130.87.70.234'(<ac on this left side).
8. Click 'SET' to the result of the steering.
9. 'Reset' will make the steers as before the last 'SET' click.
(NOTE: If you click 'SET' twice, the original setting is lost.)
What is 'Tolerance' in Online Orbit Correction
in Orbit correction, SAD try to fit orbit to the BPM data using steers.
SAD will stop the fitting when the difference between the orbit and
the BPM data become less than the 'Tolerance' for all BPMs.
Unit of 'Tolerance' is meter.
If you give too small Tolerance, SAD may not be able to find solution
and may give a strange answer.
Recomended:
'Tolerance' should be misalignment + resolution of BPMs.
(1e-4 ~ 5e-4 ???)
